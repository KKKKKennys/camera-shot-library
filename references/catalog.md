# 50 张镜头卡

按观看目的重新组织；相机、物体联动、合成转场和剪辑节奏分别使用。

## 建立与基础 · 8 张

| 卡片 | 用途 | 起始时长建议 |
|---|---|---|
| [全貌建立](../cards/foundation/silhouette-establish.md) | 先让观众读清资产轮廓、支撑关系和比例。 | 2–4 秒 |
| [缓推观察](../cards/foundation/measured-push.md) | 从已明确的全貌缓慢靠近一个值得看的细节。 | 3–6 秒 |
| [后撤交代环境](../cards/foundation/context-pullback.md) | 将局部构件放回它所属的整体空间。 | 3–6 秒 |
| [横向滑轨](../cards/foundation/lateral-track.md) | 比较相邻结构，或让侧向视差呈现空间深度。 | 3–5 秒 |
| [垂直升降](../cards/foundation/vertical-track.md) | 由低处到高处读出建筑或道具的层次。 | 3–5 秒 |
| [水平扫视](../cards/foundation/pan-survey.md) | 站在同一个观察位置，从一区域转向另一区域。 | 2–5 秒 |
| [俯仰扫视](../cards/foundation/tilt-survey.md) | 沿垂直方向揭示悬挂物、建筑高度或地面关系。 | 2–5 秒 |
| [斜向接近](../cards/foundation/diagonal-dolly.md) | 同时呈现主体的正面与侧面，让结构有体积感。 | 3–5 秒 |
