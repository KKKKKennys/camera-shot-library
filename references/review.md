# 镜头检查清单

- 起止画面能解释主体，运动中主体不会无意离开画面。
- 轨迹、朝向和速度分别连续；中途没有穿模、翻转、突停或失去观察目标。
- 景深、运动模糊、高光与遮挡不会破坏结构可读性。
- 拆装、灯光、材质与相机的联动职责清楚，关键时刻有观看时间。
- 横竖画幅分别核对完整构图，不能用拉伸补满画面。
- 对照画面使用一致的模型、机位和时间；结论只覆盖实际变化。
- 成片的时长、帧数、fps、分辨率和音轨状态与交付要求一致。
- 保留可编辑工程与素材路径；标明检查是静帧、逐帧、完整播放还是未执行。

优化记录采用：问题 → 证据帧或区间 → 实际改动 → 复查结果。没有执行的检查不要预填“通过”。


## V2 回归记录
- 同一缺陷位置保留原帧/修改帧/相邻帧对照；原本没有的形变不能被当作速度改善的代价。
- 每条结果写明帧号或区间、方法与证据；静帧、逐帧、完整播放和听音不是同一个检查。
- 计划一致性与实际媒体检查分开报告，时间线脚本通过不能填成构图、穿模、声音已通过。
- 用户要求保留音轨/原帧时核对它们，而不是仅核对新文件长度。
