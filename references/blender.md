# Blender 实现要点

## 确认现场

读取当前文件、版本、帧率、帧范围、单位、主体包围盒、相机、已有 Action 和约束。没有明确主体时先确认；不把整个场景所有对象都视为镜头主角。

## 空间与镜头

| 目标 | 可编辑实现 | 容易混淆的点 |
|---|---|---|
| 推近 / 后撤 | 相机位置轨迹与观察目标 | 透视位移和焦距变化并不等价 |
| 环绕 | 相机父级控制、路径或位置关键帧 | 目标高度、半径和滚转需要分别核对 |
| 穿行 / 升降 | 平滑路径与前方观察目标 | 位置平滑不保证朝向也平滑 |
| 拆装 | 零件独立动作，相机单独安排 | 组件动画不等同于相机运镜 |
| 光影揭示 | 灯组或材质状态与机位配合 | 曝光变化可能掩盖材质与形体 |
| 焦点交接 | 真实焦点目标与景深控制 | 焦外不是掩盖资产错误的手段 |

先确定起止构图与关键观察点，再填中间路径。依据主体尺寸规划初始距离，最后在实际相机取景中核对。不要把一组固定米数、角度或焦距当作所有项目的正确答案。

姿态插值避免无意跨越角度边界；需要时使用一致的旋转表示或明确的朝向约束。约束产生的滚转、路径切线突变和目标急转必须沿整段检查。

## 时间与保存

将建立、运动、减速、停留换算为目标帧率的帧范围。已有确定音轨与切点时保持时间线，未经授权不插帧、变速或挪动音乐。

对需要保护的动画使用副本或独立 Action / 控制对象；清楚命名相机、目标、路径与联动对象。完成后重新读取实际关键帧与帧范围，不以脚本没有报错代替结果验证。
