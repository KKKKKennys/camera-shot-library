# 制作复盘：不是加了动效就算改进

## 真实案例：NEREID V56
本页由既有制作约定、失败补帧检查、终检摘要整理。它说明 V2 规则从哪里来，不声称 V2 在过去已经运行。

**目标**：保留已有音乐、节拍和三维工程，调整前段流畅度，并在 9 秒开始中心显色。

**失败试验**：对运动段补帧后，圆环断裂，显示器、椅子、台面、门框、床和书架等出现新增拉扯。六个镜头分别找到了证据位置，原相邻两帧没有对应损伤。

**处置**：弃用问题缓存，保留原始 30fps 帧序。把轻量衔接和中心显色放到后期；9 秒起以 0.5 秒窗口揭示成品。

**既有终检记录**：1920×1080、30fps、490帧，六处旧伪影回归；原 AAC 705 个包和时间戳一致。详情见 [验收摘要](evidence/nereid-v56-review.txt)。该记录未包括主观实时播放/听音或跨手机验收。

## 变成 V2 的具体规则

| 观察 | 规则变化 | 对应文件 |
|---|---|---|
| 更高帧率可能损伤结构 | 效果前后对照同一位置，结构质量单列 | references/review.md |
| 帧差造成显色双影 | 写明源帧起点、fps、机位和尺寸，额外检查真实边缘 | references/timing-v2.md |
| 同一镜头含多个制作层 | 相机、零件、灯光和遮罩分开组织 | references/selection-v2.md |
| “文件存在”覆盖了未查项目 | 计划、实现、检查各自标注状态与证据 | SKILL.md |

## AK-50 提供的观看目的
完整轮廓的建立帧让人读清比例与工作台关系；零件拆开、俯视停留和归位解释装配结构。这里用已有作品说明选卡依据，没有为 V2 新渲演示，也不以“50 张卡”代表 50 项实渲成绩。

## V2 这轮实际验证什么
本轮以合成输入验证检索与时间线检查：帧区间空隙、重叠、未知卡名、越界素材、双层未对齐和不同 fps。脚本通过只代表元数据自洽。空间穿模、朝向突跳、构图与声音体验仍需在实际制作中验收。
